# Homepage media gallery

The homepage follows the approved B visual concept: large original media surfaces,
a single perspective, thin neutral edges and soft shadows. Source photographs supply
the color. There are no mechanical carriers, orange illumination or interaction controls.

The four sources move horizontally on a shared clock. Cited findings appear to their
right, with image crops, video excerpts, an audio quote and the example PDF chart.
The video source and its result both show real muted video, not animated posters.
The result canvas paints the same decoded stream, so overlapping surfaces stay live
without introducing a second player or a second download.
The shared playback controller gives manual playback elsewhere priority. Only one hero
video is decoded; viewport, tab visibility, reduced motion and data saver are respected.
Noninteractive video pauses are not recorded as explicit user pauses. Visible playback
is reconciled on readiness, source/result handoff and while the gallery is running.

All source assets and the independent understanding explorer remain unchanged.
