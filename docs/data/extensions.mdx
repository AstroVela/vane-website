title: Overview
---

Connect Vane Data to lakehouse formats and external data stores.

- **[Apache Iceberg](https://iceberg.apache.org/)** — A high-performance open table format for large-scale analytics. The Vane extension provides distributed query and write capabilities.
- **[Lance](https://lance.org/)** — A columnar data format designed for multimodal AI. The Vane extension provides distributed query and write capabilities, supporting dataset reads and writes, vector search, and hybrid search.
- **[Apache Paimon](https://paimon.apache.org/)** — A lakehouse table format for unified stream and batch processing. The Vane extension provides distributed query and write capabilities.
- **[Vortex](https://vortex.dev/)** — A columnar file format designed for efficient compression and computation. The Vane extension provides distributed query and write capabilities.
- **[DuckLake](https://ducklake.select/)** — A lakehouse format combining SQL analytics with data lake scalability. The Vane extension provides distributed query and write capabilities.
- **[Milvus](https://milvus.io/)** — A vector database designed for high-dimensional similarity search. The Vane extension provides distributed write capabilities, supporting distributed upserts and query result writes.
- **[Qdrant](https://qdrant.tech/)** — A vector database designed for high-dimensional similarity search. The Vane extension provides distributed write capabilities, supporting distributed upserts and query result writes.
- **[Apache Doris](https://doris.apache.org/)** — A real-time analytical database with a high-performance OLAP engine. The Vane extension provides distributed write capabilities, supporting Arrow batch writes through Arrow Stream Load.
