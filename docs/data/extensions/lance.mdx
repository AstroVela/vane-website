[Lance](https://lance.org/) is a columnar data format designed for multimodal AI.

The Vane extension provides distributed query and write capabilities, supporting dataset reads and writes, vector search, and hybrid search.

- **GitHub:** [AstroVela/lance-duckdb](https://github.com/AstroVela/lance-duckdb)
