---
title: Apache Paimon
---

[Apache Paimon](https://paimon.apache.org/) is a lakehouse table format for unified stream and batch processing.

The Vane extension provides distributed query and write capabilities.

- **GitHub:** [AstroVela/duckdb-paimon](https://github.com/AstroVela/duckdb-paimon)
- **Document:** [VANE_README.md](https://github.com/AstroVela/duckdb-paimon/blob/main_vane/VANE_README.md)
