title: Vortex

[Vortex](https://vortex.dev/) is a columnar file format designed for efficient compression and computation.

The Vane extension provides distributed query and write capabilities.

- **GitHub:** [AstroVela/duckdb-vortex](https://github.com/AstroVela/duckdb-vortex)
- **Document:** [VANE_README.md](https://github.com/AstroVela/duckdb-vortex/blob/v1.5-variegata_vane/VANE_README.md)
