Vane Data uses `vane-ai` as the distribution package and `vane` as the Python import package.

## Requirements

- Python 3.10 through 3.14. Python 3.12 is recommended and is the primary development version.
- A prebuilt wheel for your platform (see the table below). Platforms without a published wheel require a local C++ build environment.

## Supported platforms

| Platform | Prebuilt wheel | Notes |
| --- | --- | --- |
| Linux x86_64, glibc 2.28+ (`manylinux_2_28`) | Yes | |
| macOS 11+ on Apple silicon (`arm64`) | Yes | |
| Windows x64 | Yes | |
| macOS on Intel (`x86_64`) | No | Build from source |
| Linux ARM64 (`aarch64`) | No | Build from source |

Wheels are published for every supported Python version (3.10–3.14) on the three platforms marked Yes. If your platform is not covered, follow the [development guide](/docs/data/contributing/development) to build from source.

## Install a released package

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then install the released package:

```bash
uv venv --python 3.12
source .venv/bin/activate
uv pip install vane-ai
```

`pip install vane-ai` works the same way inside an existing virtual environment.

**Ray is a package dependency, not a cluster requirement.** `vane-ai` installs `ray`, but the Local Runner does not start Ray or need a cluster. Ray is only used when you configure the Ray runner.

## Optional dependencies

Install only the providers you use:

```bash
# Local embedding and classification models
uv pip install sentence-transformers transformers torch

# Hosted model providers
uv pip install openai
uv pip install anthropic
uv pip install google-genai

# vLLM-backed prompting
uv pip install vllm
```

## Verify the install

```bash
python - <<'PY'
import vane

print("Vane:", vane.__version__)
print("DuckDB:", vane.__duckdb_version__)

con = vane.connect()
con.sql("select 42 as answer").show()
PY
```
