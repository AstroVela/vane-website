This quickstart uses Vane's native file and image types to turn local images into thumbnails. It runs on your machine and needs no external Ray cluster, GPU, or model-provider credentials.

You will create three sample images, inspect their metadata, filter by width, and decode and resize the selected images with SQL.

Before continuing, complete the [Installation guide](/docs/data/quickstart/installation). Install the image extra in the same environment; it includes Pillow for the sample images and the default Python image backend:

```bash
uv pip install 'vane-ai[image]'
```

## Run Your First Multimodal Query

Save this as `quickstart.py` and run `python quickstart.py`:

```python
from pathlib import Path

from PIL import Image
import vane

# Create three local images; no downloads are needed.
assets = Path("quickstart-images").resolve()
assets.mkdir(exist_ok=True)
for name, size, color in [
    ("large", (640, 480), "navy"),
    ("medium", (320, 240), "orange"),
    ("small", (64, 64), "green"),
]:
    Image.new("RGB", size, color).save(assets / f"{name}.png")

con = vane.connect()
files = vane.from_files(
    [str(assets / f"{name}.png") for name in ("large", "medium", "small")],
    connection=con,
)
images = con.sql("SELECT image_file(file) AS source FROM files")
metadata = con.sql("""
    SELECT source, image_file_metadata(source) AS info
    FROM images
""")
thumbnails = con.sql("""
    SELECT info.width AS source_width, info.height AS source_height,
           resize(decode_image_file(source, 'RGB'), 224, 224) AS thumbnail
    FROM metadata
    WHERE info.width >= 300
""")
con.sql("""
    SELECT source_width, source_height,
           image_width(thumbnail) AS width,
           image_height(thumbnail) AS height,
           typeof(thumbnail) AS image_type
    FROM thumbnails
    ORDER BY source_width DESC
""").show()
```

The 64 × 64 image is filtered out. The two remaining images become 224 × 224 thumbnails:

| source_width | source_height | width | height | image_type |
| --- | --- | --- | --- | --- |
| 640 | 480 | 224 | 224 | `IMAGE` |
| 320 | 240 | 224 | 224 | `IMAGE` |

## What Just Happened

- `from_files(...)` created a `FILE` column from the local paths; `image_file(file)` turned each reference into an `IMAGEFILE`.
- `image_file_metadata(...)` read the encoded image's dimensions without decoding the full pixel array. SQL selected images at least 300 pixels wide.
- `decode_image_file(...)` decoded the selected references into `IMAGE` values; `resize(...)` produced fixed-size RGB images.
- `show()` ran the query and displayed dimensions and types. The `thumbnail` column holds pixels, while `source` holds a file reference. The query does not save new image files.

See [File functions](/docs/data/reference/multimodal-data/file) and [Image functions](/docs/data/reference/multimodal-data/image) for more operations. Native media acceleration is optional and is not required for this example.

## Scale from Local Ray to a Cluster

Ray is Vane's default runner. With `RAY_ADDRESS` unset, this quickstart starts a Ray runtime on the current machine; no external cluster or explicit runner configuration is required.

To run on a cluster, first replace the local sample paths with files accessible to every worker, such as shared storage or object storage. Then launch from the head node with cluster discovery enabled:

```bash
RAY_ADDRESS=auto python quickstart.py
```

Every Ray worker must have the image dependencies installed and access to the input files. Creating sample files on the head node alone does not make them available on other nodes. See [Deployment](/docs/data/deploy/deployment) before running on a cluster.
