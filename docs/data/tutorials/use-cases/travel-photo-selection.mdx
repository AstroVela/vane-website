This tutorial builds a six-photo album from 32 travel photographs. You will generate a CLIP vector for each photo and write it to PostgreSQL, search for candidates with a one-sentence English description, remove duplicate versions of the same scene, pick six, and end up with the page below.

The script generates this page as `album.html`. After completing the tutorial, run it again with a different description to select another set of photos.

The processing order is: Vane decodes the images → sentence-transformers creates CLIP embeddings → Vane writes through `PostgresSink` → pgvector retrieves candidates → deduplication and selection → album generation.

## 1. Prepare the environment

This example uses Bash on macOS or Linux and runs image embedding, writes, and photo selection on a local CPU. Prepare the components below before downloading the photographs.

| Component | Requirement |
|-|-|
| Python | 3.12; use a separate project directory for this example |
| Vane | A version that includes `PostgresSink`; Vane 0.3.0 and earlier do not include this API |
| PostgreSQL | [pgvector](https://github.com/pgvector/pgvector) 0.5.0 or later (required for HNSW indexes), plus permission to create extensions, schemas, tables, and indexes |
| Embedding model | [clip-ViT-B-32](https://huggingface.co/sentence-transformers/clip-ViT-B-32), used for 512-dimensional image and text-query vectors; about 600 MB of weights, downloaded automatically from Hugging Face on first use |

### 1.1 Prepare PostgreSQL and pgvector

If you already have a PostgreSQL instance, confirm that pgvector is installed and that your user can run `CREATE EXTENSION vector`. Without a local database, start one with the pgvector Docker image, listening only on this machine. First enter a password, which becomes the password of the `postgres` user; it is not shown as you type, and it cannot be empty:

```bash
printf 'PostgreSQL password: '; read -rs POSTGRES_PASSWORD; echo
export POSTGRES_PASSWORD
docker run -d --name vane-photo-pg \
  -e POSTGRES_PASSWORD \
  -p 127.0.0.1:5432:5432 \
  pgvector/pgvector:pg17
docker exec vane-photo-pg pg_isready -h 127.0.0.1 -U postgres
```

A new container needs a few seconds to initialize. If `pg_isready` reports `no response`, wait and run it again, then continue after `accepting connections` appears.

If another PostgreSQL server already uses port 5432 on this machine, `docker run` reports that the port is already allocated. Change `127.0.0.1:5432:5432` to `127.0.0.1:5433:5432`, and use port 5433 in `POSTGRES_DSN` below as well. If you run the command again and Docker says the container name is already in use, start the existing container with `docker start vane-photo-pg`. The existing container keeps the password from its first start, so set `POSTGRES_PASSWORD` to that password. For other installation methods, see the [pgvector installation guide](https://github.com/pgvector/pgvector#installation).

The scripts read the connection address from `POSTGRES_DSN` and the password from `POSTGRES_PASSWORD`, so the password does not need to be in the DSN. With an existing instance, adjust the DSN and set `POSTGRES_PASSWORD` in the same way:

```bash
export POSTGRES_DSN='postgresql://postgres@127.0.0.1:5432/postgres'
```

Run the remaining steps in the same terminal window. In a new window, set `POSTGRES_PASSWORD` and `POSTGRES_DSN` again, or the scripts fail with `no password supplied`.

### 1.2 Install dependencies and download the model

If [uv](https://docs.astral.sh/uv/getting-started/installation/) is not installed yet, install it first. For other environment options, see the [installation guide](/docs/data/quickstart/installation). Create a standalone directory and install the dependencies:

```bash
mkdir -p ~/vane-postgres-photo-demo/code
cd ~/vane-postgres-photo-demo
uv venv --python 3.12
source .venv/bin/activate
uv pip install "vane-ai[postgres]" sentence-transformers Pillow numpy
python -c "from vane import PostgresSink; print('PostgresSink available')"
```

Continue after `PostgresSink available` appears. The first run of `pipeline.py` downloads the CLIP model into `~/.cache/huggingface/hub`; later runs reuse the cache. You can also download it in advance:

```bash
hf download sentence-transformers/clip-ViT-B-32
```

If the environment cannot reach Hugging Face, run this command on a machine that can, then copy the corresponding model directory under `~/.cache/huggingface/hub`. On an Apple M5 Mac with 32 GB of memory, embedding, writing, and selecting the 32 photographs on the CPU took about 15 seconds, excluding the first model download.

## 2. Download the photographs and metadata

The 24 originals cover beaches, mountains, cities and food. Eight additional files beginning with `V` are crops or colour adjustments of those originals. They simulate the near-duplicates common in a photo library. Each variant shares a `duplicate_group` with its source image, so at most one can appear in the album.

These commands download only the assets and metadata used by the example. You do not need to clone the website repository:

```bash
mkdir -p images/variants
export VANE_EXAMPLE_URL='https://vane.astrovela.ai/tutorials/travel-photo-selection'
curl -fLO "$VANE_EXAMPLE_URL/sources.csv"
curl -fLO "$VANE_EXAMPLE_URL/metadata-draft.csv"
for id in B01 B02 B03 B04 B05 B06 M01 M02 M03 M04 M05 M06 C01 C02 C03 C04 C05 C06 F01 F02 F03 F04 F05 F06; do
  curl -fL "$VANE_EXAMPLE_URL/images/$id.jpg" -o "images/$id.jpg"
done
for id in V01 V02 V03 V04 V05 V06 V07 V08; do
  curl -fL "$VANE_EXAMPLE_URL/images/variants/$id.jpg" -o "images/variants/$id.jpg"
done
```

The trip names and dates in `metadata-draft.csv` were written for this demonstration; they do not come from EXIF data.

## 3. Measure the photograph metadata

Save the following as `code/prepare_metadata.py`. The script reads 32 photographs, measures their dimensions, mean luminance and edge variance, and links each derived variant to its original duplicate group.

```python
from __future__ import annotations

import csv
from pathlib import Path

from PIL import Image, ImageFilter, ImageStat

ROOT = Path(__file__).resolve().parents[1]


def main() -> None:
    with (ROOT / "sources.csv").open(encoding="utf-8") as source:
        sources = list(csv.DictReader(source))
    with (ROOT / "metadata-draft.csv").open(encoding="utf-8") as source:
        draft = {row["photo_id"]: row for row in csv.DictReader(source)}
    rows = []
    for source in sources:
        photo_id = source["id"]
        path = ROOT / source["file"]
        with Image.open(path) as image:
            gray = image.convert("L").resize((256, 256))
            brightness = ImageStat.Stat(gray).mean[0] / 255
            sharpness = ImageStat.Stat(gray.filter(ImageFilter.FIND_EDGES)).var[0]
            width, height = image.size
        original_id = source["derived_from"] or photo_id
        metadata = draft[original_id]
        rows.append({
            "photo_id": photo_id,
            "path": str(path.resolve()),
            "theme": source["group"],
            "trip": metadata["suggested_trip"],
            "captured_at": metadata["captured_at_for_demo"],
            "source_url": source["source_image_url"],
            "duplicate_group": original_id,
            "is_variant": str(bool(source["derived_from"])).lower(),
            "width": width,
            "height": height,
            "sharpness": round(sharpness, 4),
            "brightness": round(brightness, 6),
        })
    output = ROOT / "code" / "pipeline-input.csv"
    with output.open("w", encoding="utf-8", newline="") as target:
        writer = csv.DictWriter(target, fieldnames=list(rows[0]))
        writer.writeheader()
        writer.writerows(rows)
    print(f"Wrote {len(rows)} rows to {output}")


if __name__ == "__main__":
    main()
```

Run it and check for 32 rows:

```bash
python code/prepare_metadata.py
```

Brightness and sharpness are basic technical checks. They do not determine whether a photograph is good.

## 4. Create the PostgreSQL table

Save the following as `code/schema.sql`. `photo_id` is the primary key, `embedding` is a 512-dimensional pgvector column, and the HNSW index uses cosine distance.

```sql
CREATE EXTENSION IF NOT EXISTS vector;
CREATE SCHEMA IF NOT EXISTS travel_demo;

CREATE TABLE IF NOT EXISTS travel_demo.photos (
    photo_id text PRIMARY KEY,
    path text NOT NULL,
    theme text NOT NULL,
    trip text NOT NULL,
    captured_at timestamptz NOT NULL,
    source_url text NOT NULL,
    duplicate_group text NOT NULL,
    is_variant boolean NOT NULL,
    width integer NOT NULL,
    height integer NOT NULL,
    sharpness double precision NOT NULL,
    brightness double precision NOT NULL,
    embedding vector(512) NOT NULL
);

CREATE INDEX IF NOT EXISTS photos_embedding_hnsw
    ON travel_demo.photos USING hnsw (embedding vector_cosine_ops);
```

You do not need to execute this file separately. `pipeline.py` in the next step runs these statements.

## 5. Load embeddings and generate the album

Save the complete script below as `code/pipeline.py`. It includes image decoding, CLIP inference, PostgreSQL ingestion, retrieval, selection, and HTML rendering.

```python
from __future__ import annotations

import argparse
import csv
import html
import json
import os
from pathlib import Path

import adbc_driver_postgresql.dbapi
import vane
from vane import EnvironmentSecret, PostgresSink

ROOT = Path(__file__).resolve().parents[1]
MODEL = "sentence-transformers/clip-ViT-B-32"
FIELDS = [
    "photo_id", "path", "theme", "trip", "captured_at", "source_url", "duplicate_group",
    "is_variant", "width", "height", "sharpness", "brightness",
]


def connection(dsn: str):
    password = os.environ.get("POSTGRES_PASSWORD")
    if password and "password=" not in dsn:
        separator = "&" if "?" in dsn else "?"
        from urllib.parse import quote
        dsn = f"{dsn}{separator}password={quote(password, safe='')}"
    database = adbc_driver_postgresql.dbapi.connect(dsn)
    database.adbc_connection.set_autocommit(True)
    return database


def sink(dsn: str) -> PostgresSink:
    password = EnvironmentSecret("POSTGRES_PASSWORD") if os.environ.get("POSTGRES_PASSWORD") else None
    return PostgresSink(
        "photos", schema="travel_demo", dsn=dsn, password=password,
        key_columns="photo_id", worker_count=2, max_batch_rows=8,
    )


def ingest(dsn: str) -> None:
    import pyarrow as pa
    from sentence_transformers import SentenceTransformer

    os.environ.setdefault("VANE_RUNNER", "local-fast")
    input_path = ROOT / "code" / "pipeline-input.csv"
    with connection(dsn) as database:
        with database.cursor() as cursor:
            for statement in (ROOT / "code" / "schema.sql").read_text(encoding="utf-8").split(";"):
                if statement.strip():
                    cursor.execute(statement)
    with input_path.open(encoding="utf-8") as source:
        photo_ids = [row["photo_id"] for row in csv.DictReader(source)]
    rows = []
    images = []
    with vane.connect(config={"image_backend": "python"}) as conn:
        for photo_id in photo_ids:
            row = conn.sql(
                "SELECT *, decode_image_file(image_file(path), mode => 'RGB', on_error => 'null') AS image "
                "FROM read_csv(?, header = true, all_varchar = true) WHERE photo_id = ?",
                params=[str(input_path), photo_id],
            ).fetchone()
            if row is None or row[-1] is None:
                raise RuntimeError(f"Could not decode {photo_id}")
            rows.append(dict(zip(FIELDS, row[:len(FIELDS)], strict=True)))
            images.append(row[-1])
        model = SentenceTransformer(MODEL)
        vectors = model.encode(images, batch_size=8, normalize_embeddings=True)
        table = pa.table({field: [row[field] for row in rows] for field in FIELDS})
        table = table.append_column("embedding", pa.array(vectors.tolist(), type=pa.list_(pa.float32())))
        conn.register("photo_vectors", table)
        summary = conn.sql("SELECT * FROM photo_vectors").write_datasink(sink(dsn))
        print(summary)


def vector_for_query(text: str) -> list[float]:
    from sentence_transformers import SentenceTransformer

    model = SentenceTransformer(MODEL)
    return model.encode([text], normalize_embeddings=True)[0].tolist()


def candidates(dsn: str, query: str, theme: str | None) -> list[dict[str, object]]:
    vector = json.dumps(vector_for_query(query), separators=(",", ":"))
    sql = """
        SELECT photo_id, theme, trip, captured_at, source_url, duplicate_group,
               is_variant, width, height, sharpness, brightness,
               embedding <=> $1::vector AS distance
        FROM travel_demo.photos
        WHERE ($2 = '' OR theme = $2)
        ORDER BY distance ASC, photo_id
        LIMIT 24
    """
    with connection(dsn) as database:
        with database.cursor() as cursor:
            cursor.execute(sql, (vector, theme or ""))
            names = [column[0] for column in cursor.description]
            rows = [dict(zip(names, row, strict=True)) for row in cursor.fetchall()]
            cursor.execute("SELECT count(*) FROM travel_demo.photos")
            count = cursor.fetchone()[0]
            if count != 32:
                raise RuntimeError(f"Expected 32 upserted photos, found {count}")
            cursor.execute(
                "EXPLAIN SELECT photo_id FROM travel_demo.photos ORDER BY embedding <=> $1::vector LIMIT 6",
                (vector,),
            )
            (ROOT / "code" / "explain.txt").write_text("\n".join(row[0] for row in cursor.fetchall()), encoding="utf-8")
    return rows


def select_photos(rows: list[dict[str, object]], count: int = 6) -> list[dict[str, object]]:
    eligible = [row for row in rows if 0.05 < float(row["brightness"]) < 0.95]
    selected: list[dict[str, object]] = []
    seen_groups: set[str] = set()
    used_themes: set[str] = set()
    for diverse_only in (True, False):
        for row in eligible:
            if row in selected or str(row["duplicate_group"]) in seen_groups:
                continue
            if diverse_only and str(row["theme"]) in used_themes:
                continue
            selected.append(row)
            seen_groups.add(str(row["duplicate_group"]))
            used_themes.add(str(row["theme"]))
            if len(selected) == count:
                return selected
    return selected


def render_album(rows: list[dict[str, object]], query: str, output: Path) -> None:
    cards = []
    for index, row in enumerate(rows):
        photo_id = str(row["photo_id"])
        folder = "variants/" if photo_id.startswith("V") else ""
        cards.append(f"""
        <figure class="card" data-theme="{html.escape(str(row['theme']))}">
          <img src="images/{folder}{photo_id}.jpg" alt="{html.escape(photo_id)}" loading="lazy">
          <figcaption><span>{'Cover' if index == 0 else f'Photo {index + 1}'}</span>
          <strong>{photo_id}</strong> · {html.escape(str(row['theme']))}<br>
          cosine distance {float(row['distance']):.4f} · sharpness {float(row['sharpness']):.1f}</figcaption>
        </figure>""")
    document = f"""<!doctype html><html lang="en"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1"><title>Travel photo selection</title>
<style>body{{margin:0;background:#f3f0e9;color:#17221b;font-family:-apple-system,BlinkMacSystemFont,'PingFang SC',sans-serif}}
header{{padding:56px 6vw 36px;background:#17221b;color:#f8f4e8}}header p{{max-width:760px;line-height:1.7}}
main{{padding:36px 6vw}}.grid{{display:grid;grid-template-columns:repeat(auto-fit,minmax(280px,1fr));gap:24px}}
.card{{margin:0;background:white;border-radius:16px;overflow:hidden;box-shadow:0 8px 30px #17221b18}}
.card:first-child{{grid-column:1/-1}}img{{width:100%;height:280px;object-fit:cover;display:block}}.card:first-child img{{height:min(65vw,620px)}}
figcaption{{padding:18px;line-height:1.7}}figcaption span{{display:block;color:#68766c;font-size:13px;text-transform:uppercase;letter-spacing:.12em}}
button{{border:1px solid #68766c;background:transparent;padding:8px 14px;border-radius:99px;margin:4px;cursor:pointer}}
</style></head><body><header><h1>Moments worth returning to</h1><p>Query: <strong>{html.escape(query)}</strong></p>
<p>Vane decoded the photos and wrote their metadata and vectors to PostgreSQL. sentence-transformers generated CLIP embeddings, and pgvector ranked the candidates.
Duplicate groups, exposure limits and theme diversity shape the final six-photo story; similarity alone is not treated as photographic taste.</p></header>
<main><button onclick="filterTheme('all')">All</button><button onclick="filterTheme('beach')">Beach</button>
<button onclick="filterTheme('mountain')">Mountain</button><button onclick="filterTheme('city')">City</button>
<button onclick="filterTheme('food')">Food</button><div class="grid">{''.join(cards)}</div></main>
<script>function filterTheme(theme){{document.querySelectorAll('.card').forEach(card=>{{card.style.display=theme==='all'||card.dataset.theme===theme?'block':'none'}})}}</script>
</body></html>"""
    output.write_text(document, encoding="utf-8")


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--dsn", default=os.environ.get("POSTGRES_DSN", "postgresql://postgres@127.0.0.1:5432/postgres"))
    parser.add_argument("--query", default="ocean sunset and mountain lake reflections")
    parser.add_argument("--theme", choices=("beach", "mountain", "city", "food"))
    parser.add_argument("--skip-ingest", action="store_true")
    parser.add_argument("--output", type=Path, default=ROOT / "album.html")
    args = parser.parse_args()
    if not args.skip_ingest:
        ingest(args.dsn)
    rows = select_photos(candidates(args.dsn, args.query, args.theme))
    if len(rows) != 6:
        raise RuntimeError(f"Expected six selected photos, got {len(rows)}")
    render_album(rows, args.query, args.output)
    print(f"Wrote {args.output} with: {', '.join(str(row['photo_id']) for row in rows)}")


if __name__ == "__main__":
    main()
```

Run:

```bash
python code/pipeline.py
```

`PostgresSink` uses `key_columns="photo_id"`, two workers and at most eight rows per batch. Loading the same photograph again updates its existing row. Worker batches commit independently, so inspect the data already written after a partial failure before deciding how to rerun the job.

The default query is `ocean sunset and mountain lake reflections`. With the model and data supplied in this tutorial, the six selected IDs are `V04, V01, C03, B06, V08, B04`. A different model or input set can produce a different selection.

Check the row count and dimensions in a PostgreSQL client, for example with `psql "$POSTGRES_DSN"`. With the Docker instance from section 1.1, you can also run `docker exec -it vane-photo-pg psql -U postgres`:

```sql
SELECT count(*) AS photo_count,
       count(DISTINCT photo_id) AS unique_photos,
       min(vector_dims(embedding)) AS min_dimension,
       max(vector_dims(embedding)) AS max_dimension
FROM travel_demo.photos;
```

The expected values are 32, 32, 512 and 512. Open `album.html` to see the six-photo album shown at the beginning of this page.

## 6. Try another query and inspect the result

The first three vector matches are `V04, M01, V03`, all derived from the same mountain-lake original. `select_photos()` removes the second and third by `duplicate_group`, then prefers themes not already represented. If there are not enough distinct themes, it continues down the ranked list rather than forcing unrelated photographs into the page.

There is no need to rebuild the image embeddings. Supply another English query or add a theme filter:

```bash
python code/pipeline.py --skip-ingest --query "a quiet cafe after a city walk"
python code/pipeline.py --skip-ingest --query "misty mountains and a calm lake" --theme mountain
```

Each run replaces `album.html`. The theme buttons filter only the six rendered cards; they do not call the model or query PostgreSQL again.

Run the complete pipeline again. The table should still contain 32 rows:

```bash
python code/pipeline.py
```

The script also saves the nearest-neighbour query plan in `code/explain.txt`. PostgreSQL may choose a sequential scan on this 32-row table even though the HNSW index exists. With larger tables, inspect the plan again to see whether the index is used.

If results do not match expectations, check the query language, model name and normalisation first, then inspect the `duplicate_group` values. When changing embedding models, rebuild the vector column and regenerate both image and query embeddings. Vectors from different models cannot be mixed.
