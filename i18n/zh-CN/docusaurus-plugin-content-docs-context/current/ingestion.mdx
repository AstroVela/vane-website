## 按资料类型选择通道

| 输入 | 可用处理通道 | 典型结果 |
| --- | --- | --- |
| 文本 / 记录 | 内容 | 文本摘录与类型化元数据 |
| 图片 | 视觉、OCR | 匹配图片与识别文字 |
| 视频 | 视觉、语音、OCR、声音 | 帧、片段、转写与声音时间窗 |
| 音频 | 语音、声音 | 带时间定位的转写和声音窗口 |
| PDF | 内容、OCR | 页文本、识别文字与页面引用 |

选择应用真正需要的通道。视觉检索需要视觉向量模型，语音需要 ASR，声音检索需要声音向量模型，OCR 和分析分别需要对应提供方。以 `/v1/capabilities` 返回的实际组合和限制为准。

## 提供来源

可以提交内联文本或记录、上传媒体、使用大文件可续传上传，或导入允许访问的远程 HTTPS 文件。上传和导入之后使用服务管理的资源标识，客户端传入服务器路径不构成文件访问授权。

1. 准备来源与元数据。
2. 使用稳定的幂等标识提交摄取。
3. 保存返回的摄取任务和资产标识。
4. 等任务就绪后，再使用已发布的证据。
5. 连接中断时读取同一任务，避免重复提交。

单项与批量摄取共享媒体契约；批次最多 32 项，分别跟踪每项结果。摄取产生来源证据，后续分析可以产生具有独立来源说明的生成知识，详见[证据与引用](./references.mdx)。
