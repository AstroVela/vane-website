## 理解来源定位

| 证据 | 来源位置 |
| --- | --- |
| 视频帧 | 帧时间戳 |
| 视频片段 | 起止时间 |
| 语音 / 音频 | 音频时间窗 |
| 文档 | 页码 |
| OCR | 文字偏移及对应图片、视频帧或页面 |
| 声音 | 声音窗口 |

证据标识属于一个资料库和来源资产。把返回标识原样传给分析，不要编造标识或换成无关的资料库。分析引用会与被接受的输入范围进行核验。

## 区分来源证据与生成知识

来源证据记录内容来自哪里；模型生成的描述与分析是派生内容，应保留它使用了哪些来源。应用应同时展示两者，不能把生成表述当成原文引述。

例如，“杯体容量为 500 毫升”可以引用说明书第 2 页和产品介绍录音，用户打开页面或播放对应窗口就能核对。

## 在应用中提供核对入口

1. 每条事实旁保留资料库、资产和证据标识。
2. 将引用呈现为视频 / 音频时间窗、文档页码或图片。
3. 点击后在对应位置打开原始来源。
4. 保留当前结果选择，并提供返回入口。
5. 来源无法访问时保留标识，明确说明访问失败。

资产版本、权限或删除会影响后续访问。引用是来源指针，不是永久访问授权，应遵循实际服务的版本和访问契约。
