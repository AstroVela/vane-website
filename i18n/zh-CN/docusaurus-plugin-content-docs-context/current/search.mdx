## 从文本查询开始

```bash
curl "$CONTEXT_URL/v1/search" \
  -H "Authorization: Bearer $CONTEXT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "collection": "product-media",
    "query": "show the blending steps",
    "top_k": 3
  }'
```

每个命中结果带有证据标识与来源定位，后续分析应保留并使用这些标识。

## 选择检索方式

| 后端 | 适用情况 |
| --- | --- |
| `vector` | 使用已配置的向量模型进行语义文本或配对图片检索 |
| `lexical` | 在文本内容、语音转写或 OCR 中查找关键词 |
| `hybrid` | 合并语义候选与全文匹配 |
| `temporal` | 将多个视频通道的条件按时间对齐 |
| 已配置专用后端 | 使用能力响应中公布的专用检索能力 |

图片查询需要兼容的配对向量模型，图文组合遵循视频视觉查询契约，各种模态和通道并不能任意组合。

使用资产标识、类型化元数据、模态或通道缩小范围。服务支持时可指定文档页码、视频或音频时间窗。多向量配置分别召回候选，再经排序融合和可选重排得到最终结果。

分数描述检索排序，不表示事实结论的确定性；不同后端分数含义不同。稳定翻页时原样使用返回游标，过期后重新检索。希望按文件显示结果时选择资产分组。
