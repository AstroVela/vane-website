title: 概览
---

将 Vane Data 连接到湖仓格式和外部数据存储。

- **[Apache Iceberg](https://iceberg.apache.org/)** — 一种面向海量分析的高性能开放表格式。Vane 扩展提供分布式查询写入功能。
- **[Lance](https://lance.org/)** — 一种专为多模态 AI 设计的列式数据格式。Vane 扩展提供分布式查询写入功能，支持数据集读写、向量检索及混合搜索。
- **[Apache Paimon](https://paimon.apache.org/)** — 一种流批一体的湖仓表格式。Vane 扩展提供分布式查询写入功能。
- **[Vortex](https://vortex.dev/)** — 一种面向高效压缩与计算的列式文件格式。Vane 扩展提供分布式查询写入功能。
- **[DuckLake](https://ducklake.select/)** — 一种融合 SQL 分析与数据湖扩展性的湖仓格式。Vane 扩展提供分布式查询写入功能。
- **[Milvus](https://milvus.io/)** — 一款面向高维相似度检索的向量数据库。Vane 扩展提供分布式写入功能，支持分布式 upsert 及查询结果写入。
- **[Qdrant](https://qdrant.tech/)** — 一款面向高维相似度检索的向量数据库。Vane 扩展提供分布式写入功能，支持分布式 upsert 及查询结果写入。
- **[Apache Doris](https://doris.apache.org/)** — 一款提供高性能 OLAP 引擎的实时分析型数据库。Vane 扩展提供分布式写入功能，支持通过 Arrow Stream Load 写入 Arrow 批次。
