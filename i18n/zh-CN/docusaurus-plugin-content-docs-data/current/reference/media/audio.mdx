---
title: 音频函数
---

音频函数查看 `AUDIOFILE` 元数据，并把波形重采样为形状 `(frames, channels)` 的 Float64 张量。每个函数都有 Python 形式、`Expression` 方法形式和 SQL 形式，参数相同。连接的 `audio_backend`（默认 `python`，加载 `native_media` 扩展后可用 `native`）选择 SoundFile/SoXR 路径或 C++ 路径；两种后端都用 SoXR HQ，返回恰好 `ceil(解码帧数 * 目标采样率 / 源采样率)` 帧。

## 签名

```python
vane.audio_metadata(value, *, max_bytes=...) -> Expression
vane.resample(
    value, sample_rate,
    *, max_input_bytes=..., max_frames=..., max_decoded_bytes=...,
    max_output_frames=..., max_output_bytes=...,
) -> Expression
```

SQL 形式为 `audio_metadata(file)` 和 `resample(file, rate)`。目标采样率是参数，不是波形值的字段。

## 参数

| 名称 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `value` | `AUDIOFILE` 值或 `Expression` | 待查看或重采样的编码音频对象 | 必填 |
| `sample_rate` | 正整数或 `Expression` | 目标采样率（Hz） | 必填 |
| `max_bytes` | 整数或 `Expression` | 有界元数据探测预算 | 后端默认值 |
| `max_input_bytes`、`max_frames`、`max_decoded_bytes`、`max_output_frames`、`max_output_bytes` | 整数或 `Expression` | 有界解码与输出预算 | 后端默认值 |

## 返回与错误

`audio_metadata` 返回元数据 `STRUCT`（format、subtype、采样率、通道数、帧数、时长），不解码采样。`resample` 返回 `TENSOR(DOUBLE, [NULL, NULL])`，形状 `(frames, channels)`；单声道保留一个通道，空音频为 `(0, channels)`，完整流在末尾裁剪或补零，与分块大小无关。

`NULL` 输入传播为 `NULL` 波形。native 后端的采样率为 1–384000 Hz、通道数 1–64；不支持的采样率、通道数、解码器不匹配、超出资源限制、缺失音频依赖和查询取消都会传播为错误。SQL 执行每向量批次的展平采样存储上限为 256 MiB。

诊断函数 `native_audio_resample_profile(file, rate)` 运行同样的 native 解码与重采样实现，但返回计数器（各阶段耗时、读取字节、解码/输出帧数）而不是波形。

## 示例

```python
import vane

con = vane.connect()
waveform = con.sql("""
    SELECT resample(audio_file('sample.wav'), 16000) AS audio
""").fetchone()[0]
assert waveform.shape[1] >= 1
vane.close()
```

Native 执行同一查询：

```python
import vane

con = vane.connect()
vane.load_installed_extension("native_media", connection=con)
con.execute("SET audio_backend = 'native'")
con.sql("SELECT audio_metadata(audio_file('sample.wav'))").show()
```
