---
title: 图像函数
---

图像函数解码、查看、变换和编码 `IMAGEFILE` 与 `IMAGE` 值。每个函数都有 Python 形式、`Expression` 方法形式和 SQL 形式，参数相同。连接的 `image_backend`（默认 `python`，加载 `native_media` 扩展后可用 `native`）选择 Pillow/tifffile/imagecodecs 实现或 C++ 实现；`EXPLAIN` 中 native 计划显示 `native_*` 名字。

## 签名

```python
vane.image_file_metadata(value, *, max_bytes=..., max_pixels=...) -> Expression
vane.decode_image_file(
    value, mode=None, on_error="raise",
    *, max_input_bytes=..., max_pixels=..., max_decoded_bytes=...,
) -> Expression
vane.decode_image(bytes_expr, on_error="raise", mode="RGB") -> Expression
vane.crop(image, bbox) -> Expression
vane.resize(image, w, h, *, antialias=False) -> Expression
vane.convert_image(image, mode) -> Expression
vane.encode_image(image, image_format) -> Expression
vane.image_hash(
    image, *, method="phash", hash_size=8, binbits=3, segments=3,
) -> Expression
vane.image_to_tensor(image) -> Expression
```

SQL 形式为 `image_file_metadata(file)`、`decode_image_file(file, mode => ..., on_error => ...)`、`decode_image(bytes, ...)`、`crop(image, bbox)`、`resize(image, w, h)`、`convert_image(image, mode)`、`encode_image(image, format)`、`image_hash(image, ...)` 和 `image_to_tensor(image)`。`decode_image_file` 的 `mode=None` 保留源图中 `IMAGE` 可表示的模式；`decode_image` 默认输出 `IMAGE('RGB')`。

## 参数

| 名称 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `value` / `image` / `bytes_expr` | `IMAGEFILE` / `IMAGE` / `BLOB` 值或 `Expression` | 待查看、解码或变换的输入 | 必填 |
| `mode` | 模式名、`ImageMode` 或 `Expression`；`decode_image_file`/`convert_image` 可为 `None` | 结果像素模式；`None` 表示保留输入模式 | `None`（`decode_image_file`）、`"RGB"`（`decode_image`） |
| `bbox` | `(x, y, width, height)` 整数元组/列表或 `Expression` | 裁剪原点，宽高为正；输入外的像素补零 | 必填 |
| `w` / `h` | 正整数、`Expression` 或 `None` | 缩放目标宽/高；已知模式加常量尺寸得到定形结果；`NULL` 产生 `NULL` | 必填 |
| `antialias` | `bool` 或 `Expression` | `True` 在下采样时使用加宽的三角滤波 | `False` |
| `image_format` | `ImageFormat` 成员、格式字符串或 `Expression` | 以下矩阵中的 `PNG`、`JPEG`、`TIFF`、`GIF` 或 `BMP` | 必填 |
| `method` | 哈希方法名（常量） | `ahash`、`dhash`、`dhash_vertical`、`phash`、`phash_simple`、`whash`、`colorhash` 或 `crop_resistant` | `"phash"` |
| `hash_size` | 整数常量，`2`–`64` | 哈希网格尺寸；`whash` 要求 2 的幂 | `8` |
| `binbits` / `segments` | 整数常量，`1`–`8` / `1`–`16` | 颜色分桶位数与抗裁剪网格分段数 | `3` / `3` |
| `on_error` | `"raise"` / `"null"` | `"null"` 只抑制已分类的媒体格式与 codec 失败 | `"raise"` |
| `max_bytes`、`max_pixels`、`max_input_bytes`、`max_decoded_bytes` | 整数或 `Expression` | 有界的头部探测与解码预算 | 后端默认值 |

`encode_image` 遵循显式模式矩阵：PNG 接受全部八种整数模式；TIFF 接受全部十种；JPEG 接受 L/RGB；GIF 接受 L/RGB 且至多 256 色；BMP 接受 L/RGB。其他组合先用 `convert_image` 显式转换。

## 返回与错误

`image_file_metadata` 返回元数据 `STRUCT`，不解码像素。`decode_image_file` 和 `decode_image` 返回 `IMAGE`（动态，或常量模式对应 `IMAGE(mode)`）。`crop` 返回保留输入模式约束的动态图像。`resize` 在已知模式加常量尺寸时返回定形图像。`encode_image` 返回编码后的 `BLOB` 字节。`image_hash` 接受全部图像模式，返回 `FIXEDBINARY(n)` 内容相似位（MSB 优先，末字节补零），不是完整性校验；哈希选项必须是非 `NULL` 常量。

`NULL` 输入产生 `NULL`。非法坐标、模式、格式、超出资源限制、缺失 codec 依赖和查询取消都会传播为错误。每个算子每输入图像至多接受 1 亿像素和 256 MiB 像素数据。

`image_to_tensor` 返回值不变的 HWC `TENSOR`，是基础引擎的一部分，不需要图像后端。

## 示例

```python
import vane

con = vane.connect()
result = con.sql("""
    SELECT encode_image(
        crop(decode_image_file(image_file('photo.png'), 'RGBA'), [10, 20, 64, 48]),
        'PNG'
    ) AS thumbnail
""").fetchall()
vane.close()
```

该查询返回一行 PNG 编码的缩略图字节。

Native 执行同一查询：

```python
import vane

con = vane.connect()
vane.load_installed_extension("native_media", connection=con)
con.execute("SET image_backend = 'native'")
con.sql("SELECT image_file_metadata(image_file('photo.png'))").show()
```
