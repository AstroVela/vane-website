---
title: convert_image
---

`convert_image` 在不缩放的前提下改变 `IMAGE` 的像素模式与位深。Alpha 会被保留、按完全不透明补齐，或在不合成的情况下丢弃。已知目标模式保留输入的定形尺寸；逐行模式返回动态图像。

## 签名

```python
vane.convert_image(image, mode) -> Expression
```

SQL：`convert_image(image, mode)`。Expression 方法：`expr.convert_image(mode)`。

## 参数

| 名称 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `image` | `IMAGE` 值或 `Expression` | 输入图像 | 必填 |
| `mode` | 模式名、`ImageMode`、`Expression` 或 `None` | 目标像素模式；`None` 保持输入模式 | 必填 |

## 返回与错误

返回 `IMAGE`。`NULL` 图像或模式返回 `NULL`。不支持的模式报错。

## 示例

```python
import vane

con = vane.connect()
con.sql("SELECT convert_image(decode_image_file(image_file('photo.png')), 'RGBA')").show()
```
