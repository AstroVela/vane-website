Vane 通过统一类型系统处理图像、音频和视频，每个域都有两种执行后端。用本参考选择 API，并查询签名、参数、返回值和错误。Expression 调用返回惰性的 `vane.Expression`，可用 `.alias(...)` 命名。SQL 调用是投影表达式，用 `AS` 命名结果。

## 域

- [图像函数](image/index.mdx)：解码、查看、变换和编码 `IMAGEFILE` 与 `IMAGE` 值。
- [音频函数](audio/index.mdx)：查看 `AUDIOFILE` 元数据并重采样波形。
- [视频函数](video/index.mdx)：按行输出解码帧，并构建或解析可复用寻址索引。
- [多模态类型](../types.mdx)：`FILE`、`IMAGE` 和 `TENSOR` 的存储与取值契约。
- [张量函数](../tensor.mdx)：构造和查看 `TENSOR` 值。

## 后端

每个域通过 `image_backend`、`audio_backend`、`video_backend` 独立选择执行后端。三项设置的默认值都是 `python`，仅接受 `python` 或 `native`。

| 后端 | 使用的实现 | 需要安装 |
| --- | --- | --- |
| `python` | 图像用 Pillow/tifffile/imagecodecs，音频用 SoundFile/SoXR，视频用 PyAV | `vane-ai[image]`、`vane-ai[audio]`、`vane-ai[video]` |
| `native` | 可选 `native_media` C++ 扩展（FFmpeg、libsndfile、SoXR） | `vane-extension-native-media` provider wheel |

```python
import vane

con = vane.connect()
vane.load_installed_extension("native_media", connection=con)
con.execute("SET image_backend = 'native'")
```

`image_to_tensor` 与 `IMAGE` 访问器属于基础引擎，无论选择哪种后端都不需要可选扩展。
