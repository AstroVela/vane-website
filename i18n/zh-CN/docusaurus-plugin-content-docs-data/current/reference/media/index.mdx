---
title: 媒体 API 参考
---

Vane 通过统一类型系统处理图像、音频和视频，每个域都有两种执行后端。用本参考选择 API，并查询签名、参数、返回值和错误。类型见[多模态类型](types.mdx)；图像、音频、视频函数分别见[图像](image.mdx)、[音频](audio.mdx)和[视频](video.mdx)。

## 如何选择接口

| 媒体 | Python Expression | SQL Expression | 结果 |
| --- | --- | --- | --- |
| 图像 | [`vane.image_file_metadata` / `vane.decode_image_file`](image.mdx)、[`vane.crop` / `vane.resize` / `vane.convert_image` / `vane.encode_image` / `vane.decode_image` / `vane.image_hash` / `vane.image_to_tensor`](image.mdx) | `image_file_metadata`、`decode_image_file`、`decode_image`、`crop`、`resize`、`convert_image`、`encode_image`、`image_hash`、`image_to_tensor` | `IMAGE`、`TENSOR`、`BLOB`、`FIXEDBINARY` 或元数据 `STRUCT` |
| 音频 | [`vane.audio_metadata` / `vane.resample`](audio.mdx) | `audio_metadata`、`resample` | `TENSOR(DOUBLE, [NULL, NULL])` 波形或元数据 `STRUCT` |
| 视频 | [`vane.video_metadata` / `vane.read_video_frames`](video.mdx) | `video_metadata`、`read_video_frames` | 帧行，`data: IMAGE('RGB', H, W)` |

Expression 调用返回惰性的 `vane.Expression`，可用 `.alias(...)` 命名。SQL 调用是投影表达式，用 `AS` 命名结果。`vane.read_video_frames` 返回 `Relation`，每选中一帧一行。

## 后端

每个域通过 `image_backend`、`audio_backend`、`video_backend` 独立选择执行后端。三项设置的默认值都是 `python`，仅接受 `python` 或 `native`。

| 后端 | 使用的实现 | 需要安装 |
| --- | --- | --- |
| `python` | 图像用 Pillow/tifffile/imagecodecs，音频用 SoundFile/SoXR，视频用 PyAV | `vane-ai[image]`、`vane-ai[audio]`、`vane-ai[video]` |
| `native` | 可选 `native_media` C++ 扩展（FFmpeg、libsndfile、SoXR） | `vane-extension-native-media` provider wheel |

```python
import vane

con = vane.connect()
vane.load_installed_extension("native_media", connection=con)
con.execute("SET image_backend = 'native'")
```

`image_to_tensor` 属于基础引擎，无论选择哪种后端都不需要可选扩展。

## 执行保证

- 后端在表达式绑定时确定。先设置后端，再构造并执行查询。`EXPLAIN` 会显示绑定的实现（native 标量函数显示 `native_*`，native 帧扫描显示 `NATIVE_READ_VIDEO_FRAMES`）。
- 未加载 `native_media` 扩展的 native 请求在绑定时失败，早于 FILE I/O。没有自动回退。把对应选项设回 `python` 可让新绑定的查询走 Python。
- `ImageFile.decode()`、`VideoFile.frames()` 等 Python `File` 值方法始终使用 Python 实现；SQL/连接设置只管 SQL、表达式和连接绑定的视频源。
- 缺少 Python codec 包会在 I/O 之前报错，提示安装 `vane-ai[image|audio|video]`。
- `NULL` 输入直接传播为 `NULL` 结果，不调用 codec。`on_error="null"`（图像）和 `on_error="skip"`（视频帧）只抑制编码格式错误；I/O、资源限制和取消错误仍会传播。
