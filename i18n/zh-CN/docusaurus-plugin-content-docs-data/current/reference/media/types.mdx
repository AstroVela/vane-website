---
title: 多模态类型
---

Vane 以类型化的引擎值承载多模态数据：`FILE` 家族表示不可变对象引用，`IMAGE` 表示解码后的像素，`TENSOR` 表示数值数组（含音频波形）。以下六个名字都是一等 `LogicalType`，不是字符串别名。

## 类型

| SQL 类型 | 存储 | 含义 |
| --- | --- | --- |
| `FILE` | `STRUCT(url VARCHAR, content_type VARCHAR, position BIGINT, size BIGINT, checksum VARCHAR)` | 通用不可变对象引用，可带字节窗口（`position`、`size`） |
| `IMAGEFILE` | 同上五字段，`IMAGE` 媒体子类型 | 编码后的图像对象 |
| `AUDIOFILE` | 同上五字段，`AUDIO` 媒体子类型 | 编码后的音频对象 |
| `VIDEOFILE` | 同上五字段，`VIDEO` 媒体子类型 | 编码后的视频对象 |
| `IMAGE` | 动态 `STRUCT(data, channel, height, width, mode)`；定形 `IMAGE(mode, H, W)` 为稠密 `ARRAY` | 解码后的交错 HWC 像素 |
| `TENSOR(dtype, shape)` | 可变秩用 `STRUCT(data LIST, shape INTEGER[rank])`；全定形用稠密 `ARRAY` | 稠密行主序数值张量 |

`FILE` 家族的构造器为 `file`、`image_file`、`audio_file`、`video_file`；图像为 `IMAGE`、`IMAGE('RGB')`、`IMAGE('RGB', H, W)`；张量为 `tensor(data, shape)`。Python 中 `vane.File`、`vane.ImageFile`、`vane.AudioFile`、`vane.VideoFile` 是同五字段的不可变引用，`vane.image_type()` / `vane.image_type('RGB'[, H, W])` / `vane.tensor_type(dtype, shape)` 构造对应类型。

## IMAGE 模式

像素 dtype 由模式决定：

| 模式 | 像素 dtype | 通道数 |
| --- | --- | --- |
| L、LA、RGB、RGBA | UInt8 | 1、2、3、4 |
| L16、LA16、RGB16、RGBA16 | UInt16 | 1、2、3、4 |
| RGB32F、RGBA32F | Float32 | 3、4 |

泛型 `IMAGE` 存储为 Float32，一列可无损容纳全部模式；已知模式存储其原生像素 dtype。读取的单元格物化为形状 `(height, width, channels)` 的 C 连续 NumPy 数组。Arrow 用 `vane.image` 扩展承载定形图像。

## 音频特化

音频 API 使用形状 `(frames, channels)` 的 Float64 张量。两维都可逐行变化；单声道为 `(frames, 1)`。通道数必须为正，零帧（`(0, channels)`）表示空音频。重采样返回恰好 `ceil(解码帧数 * 目标采样率 / 源采样率)` 帧，在完整流末尾裁剪或补零。两种后端都用 SoXR HQ。

## 视频帧行

`read_video_frames` 每选中一帧输出一行。每行保留源 `path VARCHAR` 和原始 `file VIDEOFILE` 视图，以及按呈现顺序排列的帧元数据（`frame_index`、`frame_time`、`frame_pts`、`frame_dts`、`frame_duration`、`is_key_frame`、时间基字段）和按请求尺寸缩放的 `data: IMAGE('RGB', H, W)` 打包 RGB uint8 像素。未知的时间元数据仍为 `NULL`。

## Python 值与错误

- `file.is_image()` / `is_audio()` / `is_video()` 分类时不做 I/O：先看声明的子类型，再看 `content_type` 或 URL 后缀（仅路由提示）。`as_image()` / `as_audio()` / `as_video()` 返回同五字段的新值；不同媒体子类型之间转换抛出 `TypeError`。
- `file.stat()` 和 `file.exists()` 查看存储而不解码。SQL 表达式相等要求 `FILE` 子类型相同，并保留 SQL `NULL` 语义。
- 非 `NULL` 图像要求所有字段和像素非 `NULL`，宽高为正。非 `NULL` 张量没有 `NULL` 维度或元素；零维度是空张量，与 `NULL` 张量不同。
