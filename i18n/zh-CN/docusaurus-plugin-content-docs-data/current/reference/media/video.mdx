---
title: 视频函数
---

视频函数查看 `VIDEOFILE` 元数据，并把解码帧按行流式输出，`data: IMAGE('RGB', H, W)`。连接的 `video_backend`（默认 `python`，加载 `native_media` 扩展后可用 `native`）选择 PyAV DataSource 路径或 FFmpeg C++ 扫描；`EXPLAIN` 中 Python 显示 `DATASOURCE_SCAN`，native 显示 `NATIVE_READ_VIDEO_FRAMES`。

本页只覆盖元数据查看与流式扫描。逐行帧表达式（`video_frames`、`video_keyframes`、`get_video_frame_by_idx`）、可复用寻址索引（`build_video_index`）与诊断函数（`video_index_info`、`video_scan_stats`）不在本页范围，见 [Frames, streaming and indexes](https://github.com/AstroVela/vane/blob/main/VIDEO_FRAME_API.md)。

## 签名

```python
vane.video_metadata(value, *, max_bytes=...) -> Expression
vane.read_video_frames(
    path, image_height, image_width, is_key_frame=None,
    *, sample_interval_seconds=None, start_time=0, end_time=None,
    max_input_bytes=..., max_decoded_frames=..., max_pixels=...,
    max_partition_bytes=..., frame_limit=None, read_task_count=None,
    on_error="raise", indexes=None, connection=None,
) -> Relation
```

SQL 形式为 `video_metadata(file)` 和 `read_video_frames(source, height, width, ...)`。`read_video_frames` 的前三个参数是源、输出高、输出宽；其余选项在两种 API 中都是命名参数。

## 参数

| 名称 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `value` | `VIDEOFILE` 值或 `Expression` | 待查看的编码视频对象 | 必填 |
| `path` | 路径字符串、`os.PathLike`、`FILE`/`VIDEOFILE` 值或其列表 | 精确的输入路径或 FILE 视图；不支持目录或 glob 发现 | 必填 |
| `image_height` / `image_width` | 正整数 | 输出帧尺寸；`data` 为 `IMAGE('RGB', H, W)` | 必填 |
| `is_key_frame` | `bool` 或 `None` | 设置后只过滤关键帧 | `None` |
| `sample_interval_seconds` | 数值或 `None` | 时间戳达到下一个间隔点时输出帧 | `None` |
| `start_time` / `end_time` | 数值 | 相对流起始的闭区间时间窗口（秒） | `0` / `None` |
| `frame_limit` | 整数或 `None` | 全局有序帧上限；使用单个有序工作单元 | `None` |
| `read_task_count` | 整数或 `None` | 本地任务和 Ray 切分的文件分组数，上限为文件数 | 默认每文件一组 |
| `indexes` | 索引 `BLOB` 列表或 `None` | `build_video_index` 生成的已验证关键帧寻址索引，每个输入一份 | `None` |
| `on_error` | `"raise"` 或 `"skip"` | `"skip"` 只抑制编码格式错误 | `"raise"` |
| `connection` | 连接或 `None` | 执行扫描的查询会话 | 当前连接 |
| `max_bytes`、`max_input_bytes`、`max_decoded_frames`、`max_pixels`、`max_partition_bytes` | 整数 | 有界探测、解码与分片预算 | 后端默认值 |

## 返回与错误

`video_metadata` 返回首个非附加视频流的元数据 `STRUCT`，用 `duration` 表示所选流时长、`container_duration` 表示整个容器时长；未知时长和帧数仍为 `NULL`。

`read_video_frames` 返回 `Relation`，每选中一帧一行：`path`、原始 `file` 视图、`frame_index`、`frame_time`、时间基与时间戳字段（`frame_pts`、`frame_dts`、`frame_duration`）、`is_key_frame` 和 `data`。顶层的 `NULL`/`None` 或空列表返回具有声明 schema 的空表；列表中的 `NULL` 元素和其他媒体子类型会直接报错。绑定时校验参数，不打开视频。跨文件任务的行顺序不保证，需要时用 `ORDER BY`。

Native 视频分发只接受内置的 `VideoFrameSource` 精确类型；为子类选择 native 会在读文件前报错。

## 示例

```python
import vane

con = vane.connect()
frames = vane.read_video_frames(
    "clip.mp4", 224, 224,
    start_time=1, end_time=5, sample_interval_seconds=0.5,
    connection=con,
)
frames.select("path", "frame_index", "frame_time", "data").show()
```

```sql
SELECT path, file, frame_index, frame_time, data
FROM read_video_frames(
    'clip.mp4', 224, 224,
    start_time => 1, end_time => 5, sample_interval_seconds => 0.5
);
```

Native 执行同一扫描：

```python
import vane

con = vane.connect()
vane.load_installed_extension("native_media", connection=con)
con.execute("SET video_backend = 'native'")
frames = vane.read_video_frames("clip.mp4", 224, 224, connection=con)
```
