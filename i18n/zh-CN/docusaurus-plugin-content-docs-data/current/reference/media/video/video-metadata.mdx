`video_metadata` 用有界流信息探测查看首个非附加视频流。

## 签名

```python
vane.video_metadata(value, *, max_bytes=8388608) -> Expression
```

SQL：`video_metadata(file [, max_bytes])`。Expression 方法：`expr.video_metadata(...)`。

## 参数

| 名称 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `value` | `VIDEOFILE` 值或 `Expression` | 待查看的编码视频对象 | 必填 |
| `max_bytes` | 整数或 `Expression` | 有界元数据探测预算 | `8 MiB`（上限 `64 MiB`） |

## 返回与错误

返回 `STRUCT`，含 `width`、`height`、`fps`、`duration`、`container_duration`、`frame_count` 和 `time_base`。`duration` 只描述所选视频流，`container_duration` 描述整个容器。未知时长和帧数仍为 `NULL`。

## 示例

```python
import vane

con = vane.connect()
con.sql("SELECT video_metadata(video_file('clip.mp4'))").show()
```
