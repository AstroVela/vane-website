title: encode_image
---

`encode_image` 把 `IMAGE` 编码为图像文件格式并返回字节。

## 签名

```python
vane.encode_image(image, image_format) -> Expression
```

SQL：`encode_image(image, format)`。Expression 方法：`expr.encode_image(image_format)`。

## 参数

| 名称 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `image` | `IMAGE` 值或 `Expression` | 输入图像 | 必填 |
| `image_format` | `ImageFormat` 成员、格式字符串或 `Expression` | 以下矩阵中的 `PNG`、`JPEG`、`TIFF`、`GIF` 或 `BMP` | 必填 |

`encode_image` 遵循显式模式矩阵：PNG 接受全部八种整数模式；TIFF 接受全部十种；JPEG 接受 L/RGB；GIF 接受 L/RGB 且至多 256 色；BMP 接受 L/RGB。其他组合先用 `convert_image` 显式转换。

## 返回值与错误

返回编码后的 `BLOB` 字节。`NULL` 图像或格式返回 `NULL`。不支持的格式，以及矩阵之外的模式/格式组合会报错。

## 示例

```python
import vane

con = vane.connect()
con.sql("""
    SELECT encode_image(
        crop(decode_image_file(image_file('photo.png')), [10, 20, 64, 48]),
        'PNG'
    ) AS thumbnail
""").show()
```
