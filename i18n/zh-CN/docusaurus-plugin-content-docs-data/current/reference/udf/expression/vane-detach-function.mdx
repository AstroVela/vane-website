---
title: vane.detach_function
---

`vane.detach_function` 从 Vane 连接中移除已经注册的 SQL 函数。

## 签名

```text
vane.detach_function(
    alias: str,
    *,
    connection: Any | None = None,
) -> None
```

## 参数

| 参数 | 类型 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `alias` | `str` | 要移除的 SQL 函数名 | 必填 |
| `connection` | Vane 连接或 `None` | 持有该函数的连接；省略时使用 `vane.default_connection()` | `None` |

## 返回值与错误

函数返回 `None`。指定函数无法移除时，底层连接错误会直接向上传递。

## 示例

```python
import vane


@vane.func(return_dtype="BIGINT")
def identity(value):
    return value


vane.attach_function(identity, parameters=["BIGINT"])
vane.detach_function("identity")
vane.close()
```
